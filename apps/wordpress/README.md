# WordPress admin

Локальная WordPress-среда для будущего управления каталогом и контентом.

1. Скопируйте `.env.example` в `.env`.
2. Замените оба демонстрационных пароля случайными длинными значениями.
3. Из корня репозитория запустите `npm run wordpress:up`.
4. Откройте <http://localhost:8080> и завершите стандартную установку WordPress.

База данных не публикует порт наружу, веб-порт привязан только к `127.0.0.1`, а редактор PHP-файлов в админке отключён. Данные Docker хранятся в именованных томах и не попадают в Git.
